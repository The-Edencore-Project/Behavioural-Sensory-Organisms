# 🌱🐢 Behavioural Sensory Organisms  
The foundational repository for a new class of non‑cognitive domestic organisms built from sensory pressure, reflex protocols, hierarchical dominance, and global behavioural posture.

---

## 🌿 What This Project Is  
This repository defines the theory, architecture, and implementation of Behavioural Sensory Organisms (BSOs). These systems do not think, plan, interpret, or model the world. They behave.

A BSO is a minimal organism built from sensors, reflexes, suppression rules, and global modes. Its behaviour emerges from environmental pressure rather than cognition.

---

## ⚙️ What a BSO Does  
A BSO feels the world through sensors, reacts through reflex protocols, resolves conflicts through dominance, and expresses itself through a single global posture.

This creates a stable, predictable behavioural identity suitable for IoT environments and domestic systems.

---

## 🧩 Core Principles  
- **Non‑cognitive**: no planning, reasoning, or world models.  
- **Reflexive**: behaviour emerges from protocols, not logic trees.  
- **Hierarchical**: higher‑tier reflexes suppress lower‑tier ones.  
- **Mode‑driven**: the organism collapses into Calm, Active, or Protective.  
- **Deterministic**: stable, explainable behaviour under all conditions.

---

Future devices, engines, and variants will derive from the specifications defined here.

# 🐢 Behaviour‑OS as an Organism  
### A Structural Mapping Between the Codebase and a Living System

Behaviour‑OS is best understood as a **spine‑based animal**: a slow, pressure‑driven organism that feels the world through its shell and responds through deterministic muscle pathways.  
It does not think. It does not interpret. It **reacts**.

This README describes how each folder in the Behaviour‑OS architecture corresponds to a real anatomical function in a tortoise‑like creature.

---

## 🫀 Runtime — The Heartbeat  
The Runtime layer provides the organism’s internal rhythm.  
It maintains cycles, timing, and baseline regulation — the equivalent of a tortoise’s steady, autonomous heartbeat that keeps the body alive regardless of external conditions.

---

## 🟦 Perception — The Shell Nerve Grid  
A tortoise’s shell is alive, vascular, and wired with nerves.  
It feels **pressure, vibration, temperature, and disturbance** across its surface.

Perception functions the same way:  
it converts raw sensor input into a **pressure map**, not a semantic interpretation.  
The organism “feels” the house as gradients and deltas, not as concepts.

---

## 🟧 Reflex — The Muscle Fibres  
Reflex contains 26 independent behavioural fibres.  
Each one fires when its specific pressure threshold is crossed.

There is no cognition here — only deterministic reaction, the same way a tortoise’s muscles twitch in response to shell pressure or ground vibration.

---

## 🟨 Dominance — The Spine  
If all reflexes fired at once, the organism would thrash.  
Dominance resolves this by acting as the **spinal coordinator**:

- selecting the dominant reflex  
- suppressing noise  
- preventing contradictory movement  

It is the coherence engine that keeps the organism stable.

---

## 🟥 Posture — The Body Position  
Tortoises don’t express emotions; they express **stances**: withdrawn, alert, extended, braced.  
Posture encodes these outward behavioural states.

It is the visible configuration of the organism after reflex and dominance resolve internal tension.

---

## 🟪 Utils — The Skeleton  
The skeleton doesn’t move much, but it holds everything together.  
Utils provides the rigid structural components — math, helpers, shared tools — that support the rest of the organism.

---

## 🟫 Identity — The Shell Boundary  
Identity defines the organism’s shape and limits.  
A tortoise’s shell is the boundary between:

- inside vs outside  
- safe vs unsafe  
- self vs not‑self  

Identity performs the same role in Behaviour‑OS:  
it defines constraints, rules, and the edges of the system’s behavioural domain.

---

## 🧩 Summary  
Behaviour‑OS is a **pressure‑driven domestic organism**:

- it feels through its shell  
- reacts through muscle fibres  
- stabilizes through its spine  
- expresses itself through posture  
- maintains itself through rhythm  
- defines itself through boundaries  

This README provides the biological analogy that mirrors the architecture’s true design:  
**a mechanical tortoise built from behaviour, tension, and posture rather than thought.**
