# 🌌 **COMBINATORIAL BEHAVIOUR IN EDENSHELL**  
### *A Mode 3 Concept Paper on How 250 Parameters Become Millions of States*

---

# 1. **Introduction**
Edenshell is built from ~250 hand‑tuned parameters. On paper, that number seems small. But in practice, it produces a behavioural space so large it behaves like a living organism.

This paper explains how a few hundred parameters explode into millions of possible states — not through intelligence, but through **combinatorial interaction**.

Edenshell is not a mind. It is not an AI. It is a **behavioural creature** whose richness comes from the way its parameters multiply, feed back, and modulate each other.

---

# 2. **Why Behavioural Systems Don’t Scale Linearly**
In a mechanical system, parameters add.
In a behavioural organism, parameters **interact**.

Edenshell’s parameters are not independent knobs. They are:
- weighted
- cross‑linked
- state‑dependent
- feedback‑driven
- globally modulated

This means every parameter influences multiple others, creating a **combinatorial explosion**.

---

# 3. **The Three Behavioural Layers**
Edenshell’s behaviour emerges from the interaction of three layers:

## **1. Sensors**
Six sensors, each with:
- thresholds
- smoothing
- noise floors
- scaling
- hysteresis

Even conservatively, each sensor has ~5 meaningful states.

**6 sensors → 5⁶ = 15,625 sensor states**

## **2. Protocols**
26 behavioural protocols, each with:
- trigger thresholds
- cooldowns
- sensor weightings
- state transitions

Each protocol can be:
- idle
- primed
- active
- recovering

**26 protocols → 4²⁶ ≈ 70 trillion protocol states**

## **3. Global State**
~15 parameters controlling:
- tension
- drift
- decay
- smoothing
- mood

Even with only 3 meaningful ranges each:

**15 globals → 3¹⁵ = 14,348 global states**

---

# 4. **Multiplying the Layers**
The total behavioural space is:

	sensor states × protocol states × global states

Even with ultra‑conservative assumptions:

- 15,625 sensor states
- 70,000,000,000,000 protocol states
- 14,348 global states

The result is a behavioural space so large it is effectively infinite.

Edenshell will never visit most of these states — but it doesn’t need to. Even a tiny fraction yields **millions of distinct behaviours**.
