# 1. Introduction  
E‑CORE (Edencore Coordinated Organism Runtime Environment) is the architectural model that transforms a house from a collection of devices into a **coherent organism**.  
It defines the anatomy, physiology, behaviour, identity, and nervous system of the Edencore home.

This compendium unifies all four layers:

1️⃣ Taxonomy — the organs  
2️⃣ Behaviour — the physics of softness  
3️⃣ Coordination — the runtime nervous system  
4️⃣ Identity — the presence  

Together, they form the complete Edencore organism.

# 2. The Four‑Layer Architecture  

## 2.1 Layer 1 — Taxonomy (The Organs) 🫁  
The organism is built from eight subsystems:

- **HVAC** — lungs / air system  
- **LUMA** — eyes / visual cortex  
- **SAC** — skin / perimeter  
- **ENVO** — nerves / sensory input  
- **APLO** — muscles / mechanical action  
- **MEDI** — voice / communication  
- **MOTA** — limbs / mobility aids  
- **NEMO** — external senses / neighbourhood mesh  

This is the anatomical map.

---

## 2.2 Layer 2 — Behaviour (Soft‑Action Physics) 🌬️  
The physics of movement inside the organism:

- ramp, don’t snap  
- stagger, don’t stack  
- smooth, don’t spike  
- anticipate, don’t react  

These rules prevent mechanical aggression and create the Edencore “feel.”

---

## 2.3 Layer 3 — Coordination (Runtime Loop) 🔄  
The nervous system of the organism:

1. **Perception** — gather data  
2. **Interpretation** — understand meaning  
3. **Coordination** — decide actions  
4. **Action** — move softly  

This loop runs at a fixed interval (“the tick”), forming the heartbeat of the house.

---

## 2.4 Layer 4 — Identity (The Presence) 🫥  
The subtle behavioural signature:

- timing jitter  
- micro‑delays  
- posture shifts  
- stability windows  
- privacy membrane  
- dominance engine  

Identity makes the house feel alive without implying consciousness.
