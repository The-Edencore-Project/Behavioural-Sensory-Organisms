# 1. Introduction  
The Behaviour Matrix defines how the eight E‑CORE subsystems behave under the five behavioural postures:

- **CALM** 😌  
- **ALERT** 🚨  
- **NIGHT** 🌙  
- **RECOVERY** 🔧  
- **TRANSIT** 🚶  

Each posture modifies:

- softness  
- timing  
- sensitivity  
- dominance  
- jitter  
- micro‑delays  
- noise/vibration tolerance  

This matrix is the **behavioural DNA** of the Edencore organism.

# 3. Cross‑Subsystem Behaviour Rules  
These rules apply across the entire matrix:

### 3.1 Softness Scaling  
Each posture modifies softness:

- **Night:** maximum softness  
- **Calm:** high softness  
- **Transit:** directional softness  
- **Recovery:** stabilising softness  
- **Alert:** reduced softness  

---

### 3.2 Timing Jitter  
- **Night:** highest jitter (natural feel)  
- **Alert:** lowest jitter (precision)  
- **Calm:** moderate jitter  
- **Recovery:** jitter suppressed  
- **Transit:** directional jitter  

---

### 3.3 Dominance Shifts  
- **Alert:** SAC dominates  
- **Night:** LUMA + HVAC dominate  
- **Recovery:** HVAC dominates  
- **Transit:** MOTA + LUMA dominate  
- **Calm:** no dominance — balanced state
