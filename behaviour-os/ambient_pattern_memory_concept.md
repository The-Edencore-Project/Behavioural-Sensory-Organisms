# 1. **Overview**
Ambient Pattern Memory (APM) is the foundational memory architecture of Edencore. It enables a system like Edenshell to behave with uncanny sensitivity without ever crossing into cognition, logging, or AI‑style interpretation. APM is memory as **state**, not memory as **history**. It is the accumulation of physical, sensory, and statistical drift over time.

APM is fictional as a named system but fully grounded in real‑world physics: hysteresis, baseline drift, resonance change, and long‑term averaging. It is a new computational category designed for ambient, domestic, emotionally safe environments.

---

# 2. **Core Principle: Memory Without History**
APM does not store events. It stores **baselines**.

A baseline is a single evolving value representing the system’s current understanding of “normal.” Examples include:
- average noise level
- average vibration signature
- average airflow pattern
- average temperature gradient
- average movement density

These baselines update slowly over time. The update itself *is* the memory.

APM never stores:
- logs
- recordings
- timestamps
- identities
- sequences
- meaning

It remembers the present, slowly.

---

# 3. **The Four Layers of APM**
APM emerges from four interacting layers. None of them are intelligent; together they create environmental instinct.

## 3.1 Structural Hysteresis Layer
The physical structure of the environment retains micro‑changes:
- wood tension shifts
- metal resonance changes
- frame flex patterns
- floorboard vibration signatures

These changes accumulate into a long‑term physical baseline.

## 3.2 Sensor Drift Layer
Sensors naturally drift. Instead of correcting this drift, Edencore uses it as memory:
- microphones shift sensitivity
- pressure sensors shift zero‑points
- airflow sensors shift response curves

Drift becomes long‑term familiarity.

## 3.3 Environmental Baseline Layer
The system continuously averages environmental data:
- noise
- movement
- airflow
- temperature
- vibration

This forms the “weather” of the home.

## 3.4 Threshold Response Layer
When incoming data deviates from baseline beyond a threshold, the system reacts. This is instinct, not interpretation.

---

# 4. **Baseline Updating: The Memory Engine**
APM uses rolling averages to update baselines. A typical update might look like:

new_baseline = (old_baseline * 0.99) + (current_reading * 0.01)

This slow drift is the entire memory mechanism.

No logs. No history. No recall.

---

# 5. **Why APM Feels Intelligent**
APM produces behaviour that appears cognitive because humans interpret pattern‑based reactions as intent.

Examples:
- A wedding party is loud but rhythmic → baseline‑compatible.
- Tommy’s friends are chaotic and spiky → baseline‑violating.

APM does not know *why* these differ. It only knows the **pattern mismatch**.

Humans supply the meaning.
